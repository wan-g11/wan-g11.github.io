|浏览量:

cli常用命令

linux终端常用命令

分隔符以/为主

pwd 查看当前路径

cd 去某个路径下

touch 创建某个文件

makir 创建某个文件夹

ls 和ls - la 列出当前目录下的文件（-la有隐藏文件）

rm 删除

vim 编辑器，里面用i（insert），esc退出编辑:wq（write and quit）

nano 查看内容，也可编辑

cat 查看内容

truncate 剪切

open 打开文件夹(用浏览器打开文件)，open ./代表打开当前文件夹（.代表当前文件夹）

clear 清理终端记录

code 用vscode打开文件

mv 旧文件名 新文件名 （改名,同时也可以移动）

powershell命令差不多，需要用到再查

开发需要了解的互联网名词

输入网址(url)->浏览器查ip->DNS解析域名为ip发给浏览器->浏览器根据ip找到服务器并通过端口连接对应服务（nginx在服务器上面进行管理转发）->服务器收到请求并response网页内容返回给浏览器->浏览器显示网页

服务器

上面可以放想被查看的内容，就相当于一台电脑持续开机放到公网上

ip地址

ip地址定位互联网上一台设备
ABCD类地址和私有地址啥的暂时不过多介绍

域名

aad.com 啥的，方便他人记忆输入，用DNS解析域名变为ip地址，访问域名本质访问ip

端口

端口对应了服务器下不同服务的入口
eg：域名:80，http默认端口号80，https默认443，

访问错误

回答：访问不到域名需要进行故障排查

  1. 域名解析问题：包括输入错误，dns 解析失败，域名过期
  2. 网络不稳定：网络断开，防火墙，网络审查
  3. 服务器端问题：死机，流量暴增，正被攻击
  4. 端口问题：网线更换了非常见端口
    解决方案：
  5. 换个网站
  6. 换个设备
  7. 看浏览器提示
  8. 开启无痕浏览
